# STO & Vehicle Management System

Phase 1 SAP-inspired internal logistics UI with Dashboard, Vehicle Planning, Vehicle Status Tracking, Raipur Database and Excel Upload/Preview.

## GitHub Pages
Set Pages to `Deploy from a branch`, branch `main`, folder `/ (root)`. The root `index.html` is intentionally browser-ready and does not require a build step.

Excel preview loads SheetJS from jsDelivr at upload time.
